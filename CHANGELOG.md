## [1.0.0] - 2026-08-21

### Added

- Offline queries for contacts, call logs, SMS, and calendar events.
- Runtime permission requests for each data source.
- Masked samples and record counts for before/after comparison.
- Explicit backup exclusion and no network permission.
- Android Lint and GitHub Actions build checks.
